# 📊 Executive Sales Target & Performance Dashboard

لوحة تحكم تفاعلية متقدمة لتحليل أداء المبيعات ومقارنة المستهدف بالمبيعات الفعلية (`Target vs Actual`) عبر السنوات (2024، 2025، 2026 وما بعدها) وفئات المنتجات (`Min`, `Syn`, `DEO`, `Fluids`).

## ✨ المميزات الرئيسية
- **الحفاظ الكامل على البيانات الأصلية:** قراءة مباشرة من ملف Excel (`Total_Sales.xlsb` / `.xlsx`) دون تعديل الملف أو اختراع قيم مفقودة.
- **طبقة تدقيق ومطابقة محاسبية (Data Reconciliation):** كشف وعرض أي فروقات بين إجماليات Excel المجمعة والمجموع الفعلي للأشهر.
- **تصميم تنفيذي ثنائي اللغة (عربي RTL / إنجليزي LTR):** متوافق مع هوية لوحات تحكم الشركات الكبرى.
- **تحليل شامل:** مؤشرات أداء رئيسية (KPIs)، تحليل شهري، سنوي، ربع سنوي (Q1–Q4)، نصف سنوي (H1–H2)، وتحليل عميق لكل منتج.
- **تصدير احترافي:** تنزيل كافة الجداول والتقارير بصيغة Excel متعدد الأوراق أو CSV.
